# Копии графики FLUIDE

Эта папка содержит копии файлов оформления сайта. Исходные файлы остаются на своих местах; сайт продолжает использовать исходные пути.

- Корень: логотип CMS, варианты favicon и `site-icons.js` — источник встроенных SVG-иконок для локального открытия страниц.
- `assets/brand/`: основной логотип в двух цветах, логотипы служб доставки и декоративный SVG.
- `assets/icons/`: набор пиктограмм, QR-код карты лояльности и иконки авторизации.
- `assets/icons/individual/`: 26 отдельных SVG-файлов, извлечённых из набора пиктограмм и встроенных иконок главной страницы. Например, `shopping-cart.svg` — корзина, `heart.svg` — избранное, `arrow-right.svg` и `move-right.svg` — стрелки.
- `assets/fonts/`: шрифты Onest и Mazzard, используемые в оформлении.

Фотографии товаров, баннеры и черновые изображения редизайна сюда не включены: это отдельные наборы изображений в `assets/products/`, `assets/product-line/`, `assets/editorial/` и `assets/media/`.
